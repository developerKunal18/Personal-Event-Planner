# Personal Event Planner

A simple Python command-line application to organize personal events,
manage guest counts, track budgets, and monitor event status.

## Features

- Add new events
- View all events
- Search by event name, category, or location
- Filter events by status
- Update event details
- Delete events
- Manage guest counts
- Track event budgets and expenses
- Display event statistics
- Store records using JSON

## Technologies Used

- Python
- JSON
- File Handling
- Lists and Dictionaries
- Date and Time Handling
